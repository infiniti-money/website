# Học Web — Bắt đầu từ trang trắng

Một website học tạo website bằng tiếng Việt, dành cho người mới bắt đầu. Dự án dùng HTML, CSS và JavaScript thuần, không cần cài thư viện.

## Tính năng

- Lộ trình 4 chặng: HTML, CSS, JavaScript và xuất bản website.
- Bộ lọc bài học theo từng chặng.
- Đánh dấu bài đã hoàn thành và lưu tiến độ bằng `localStorage`.
- Sao chép nhanh đoạn HTML đầu tiên.
- Giao diện tương thích điện thoại, máy tính bảng và máy tính.
- Tôn trọng tùy chọn giảm chuyển động của hệ điều hành.

## Chạy dự án

Mở `index.html` trong trình duyệt. Không cần cài đặt hoặc chạy máy chủ.
